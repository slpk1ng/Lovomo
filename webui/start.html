定时任务（主动问候 / 例行消息）

支持间隔、每日、每周触发；可发送固定话术或让 LLM 以角色身份生成内容。会话 ID 留空表示发给所有留下过聊天记录的会话。总开关见「配置文件 → 定时任务与主动消息」。

节日 / 纪念日问候

每天在配置的时刻（greeting_check_time）自动检查并发送；用户生日会从「用户画像」中自动读取。

聊天中说出「提醒我…」即可自动创建（需在配置中开启待办功能）；此处可手动添加与管理。

表情包

每个子文件夹是一种情绪分类（可与 LLM 输出的情绪名对应）；「default」为兜底、「any」为任意情绪都可能随机抽取。总开关与触发概率见「配置文件 → 表情包」。开启「识图自动收藏表情」后，识图过程中被 LLM 判定为有趣/值得收藏的图片会自动保存到对应情绪分类，并在之后相同情绪的回复里按概率发出。

工具调用 (Function Calling)

LLM 可在回复时调用这些工具并把结果融入回答。总开关 tools_enabled 与命令类工具授权在「配置文件 → 工具调用」中。

联网搜索

选择 web_search 使用哪个搜索引擎；选项与说明由后端引擎注册表提供，新增引擎后此处自动出现。用户直接发链接时，无论模型是否主动调用，都会先用 web_fetch 抓取一次网页内容。

知识库 RAG

上传文档后，角色回答时可自动检索相关内容注入上下文。需配置嵌入模型（默认 nomic-embed-text，可通过 ollama pull 获取）。总开关见「配置文件 → 知识库 RAG」。

用户画像

按 QQ 号记录用户偏好与生日；开启 profiles_auto_extract 后可由 LLM 自动从对话中提取。生日匹配当日时会自动送上祝福。

自主学习

开启后每隔若干条用户消息扫描一次近期对话，自动学习其中的黑话、俚语与专有表达，并在回复时按学到的含义理解。把握不足的词条不会直接生效，而是进入下面的「待确认」列表由你裁决；确认前不参与回复。总开关与参数见「配置文件 → 自主学习」（默认开启）。

待确认

这些词条是 LLM 推断出来但把握不足的，通过后才会注入回复；也可以改完含义再通过。

使用教程

以下内容按「先配通、再调优、出问题怎么查」的顺序整理，并写清了每类现象背后的原因与对应设置。 所有功能都必须先打开对应开关才会生效。

一、每个页面的作用

1. 配置文件：所有运行参数与功能总开关。左侧有锚点导航，右上角可切换预设（把当前配置存一份在本机，之后随时切回来）。

2. 聊天记录：查看/管理会话与历史，可单会话或整包导出导入。

3. 情绪音频：每个情绪文件夹 = 一套参考音频，每段音频可单独填写它念的文字；上传后可试听。

4. 定时任务：自定义定时消息、节日/生日问候、待办提醒。

5. 统计面板：消息量、情绪分布、角色心情值与实时性能。

6. 高级功能：表情包、工具调用、知识库 RAG、用户画像、自主学习。

7. 日志输出：排查问题的第一现场，详见第五节。插件输出的日志也会出现在这里（带 [插件] 前缀）。

8. 插件市场（测试版）：管装插件—— 上传自己的 .zip 包、打开插件目录、刷新在线市场。 安装前会自动做安全扫描，含高危操作的插件需要你确认后才会装上。

9. 插件：管已装插件——所有安装的插件都在这里， 可以启用/停用/卸载；带功能页的插件，点卡片空白处就能进去设置。

二、最小可用配置

1. LLM 接口：在「LLM 大模型」里选对接口类型。 本地 Ollama 用 ollama；LM Studio、llama.cpp（llama-server，地址要带 /v1）、 vLLM、云端 API 一律用 openai。服务地址、模型名要与你的服务完全一致。

2. TTS：「TTS 服务与模型」里选本地还是云端。本地填 GPT-SoVITS 服务地址（默认 http://127.0.0.1:9880）、 模型目录、参考音频根目录，文本语言要与参考音频的实际语言一致；云端填服务商地址、模型与音色。

3. 情绪音频目录：参考音频根目录下的每个子文件夹就是一个情绪 （如 pingjing、gaoxing），文件夹里放参考音频，文字按音频同名 txt 填写 （可用「一键识别」自动生成；某段音频没单独填写时，用文件夹里的 asr.txt， 再没有就用配置里的「默认参考音频文本」兜底）。 模型/其他杂物目录不会被误识别成情绪。

4. 验证：保存配置后看日志——启动时会打印 LLM 连通性探测结果、扫到的情绪数量、 调度任务注册情况。有 [警告] 就先解决它，再谈调优。

三、参数怎么调（按效果分类）

· 回复太长/太慢：「历史消息条数」控制模型能看到的对话长度（默认 8）； 「回复生成超时」别设太小，本地推理模型首字就要几秒。

· 语音与文字对不上、语音少了某个词： 打开「TTS 详细日志」，日志会分别打印LLM 交过来的完整台词与实际送去合成的文本。 两者内容字不一致时日志会明确写出「清洗前后内容字不一致」。 另外「交叉渐变长度」越大过渡越柔和，但不要超过单句时长。

· 情绪老是"平静"：打开「情绪判定规则引导」（默认开）。 关掉它模型更容易把所有句子都判成默认情绪；也可以填「自定义情绪判定补充规则」， 例如"只要主人夸我可爱，就必须用 haixiu"。

· 角色漏回消息：检查「回复审判与心情」——这两个是独立开关： 「LLM 判断是否需要回复」会让模型判定"这条不值得回"而真的不回； 「记录角色心情值」只更新心情，不会拦任何回复。 想保留心情值又不想漏回消息：只开心情值、关掉回复审判。 相应地，心情值影响回复概率的那几个参数只在两个开关都打开时才出现。

· 主动消息/节日问候话题对不上： 「主动消息/问候携带的历史条数」（默认 6）会把最近几条对话全文发给模型， 更早的内容用摘要压缩（摘要来自「对话上下文自动摘要」，建议同时打开）。 设为 0 则不携带历史。

· 主动消息从来不发：确认「主动消息（闲置唤醒）」已开， 并注意三个限制：闲置阈值、静默时段、单会话每日上限； 若开了「回复前不再主动」，用户没回复之前不会再开口。 启动时日志会打印"已恢复 N 个会话的闲置计时"。

· 生成了语音但没声音/半截语音：日志里出现"分段音频合并已降级为…"说明合并走了兜底路径 （内容不丢，只是过渡更生硬）；出现"TTS 合成失败"则去看 TTS 服务本身。

四、工具调用

1. 总开关：「工具调用」分组里的「工具调用 (Function Calling)」； 每个工具还要在「高级功能 → 工具调用」里单独启用（表格里勾一下就会保存）。

2. 触发方式怎么选： 关键词门控最稳，但口语化请求可能漏； LLM 自主判断会先判断消息是否真的需要客观信息（时间/计算/天气/搜索/链接等）， 闲聊类消息直接跳过工具流程，回复更快更自然； 全部放行不做门控，模型容易"什么都去调一遍"，一般不建议。

3. 天气：用户没说地点时，角色不会自己猜一个城市。 想让它在用户没说地点时也能查，请在工具编辑里填「默认城市」。

4. 安全搜索：三档。 无不限制；一般（默认）允许 R16+ 站点但过滤 R18 内容； 严格连低俗、暗示的站点与内容一并过滤。 除关键词过滤外，还会给支持安全搜索的引擎（SearXNG/Bing/Google News/Brave）带上它们各自的参数。 过滤后结果变少是正常现象，日志里会写明过滤了几条。

5. "搜索只出来前几条/像被截断"：一次搜索给模型的全部结果受 「搜索总字数预算」限制（默认 4000 字）。预算用完后，后面的结果会被整条省略 （摘要绝不截半句），并在结果里注明"因长度限制省略 N 条"。 想看到更多条：把「每次搜索返回条数」和「搜索总字数预算」一起调大 （条数 × 每条约 300 字 ≤ 预算），或在「显示完整日志」下查看——完整模式不会被截断 （仅极端情况下有 40 万字符的兜底上限，触发时日志会写明）。

6. 工具输出在日志里看不全：把「工具输出日志字数上限」设为 0（默认）即为完整输出。

五、出问题了怎么查（按现象对照）

· 完全没有回复：先看日志有没有"收到私聊/群聊 …"。 没有 → 检查 NapCat 连接与「群聊需要@才回复」；有 → 看后面是"回复审判决定不回复"还是请求超时。 识图失败会降级为普通文本回复，日志里会写"识图失败，降级为普通文本回复"。

· 回复和上一条对不上/像没看到图：图片若被判定为"无需回复"，系统仍会把画面描述写进历史， 用户随后问"这个怎么样"时会重新调用识图模型；日志里会有 "本条消息指向刚才那张未被真正看过的图片"的提示。

· 待办提醒内容很怪（例如提醒"再提醒我"）： LLM 提取模式会结合最近对话把"5分钟后再提醒我吧"还原成真正的事项（如"睡觉"）； 正则模式没有上下文可用，这类空指令会被直接丢弃（日志有记录）。 想更准就把「待办提取方式」设为 llm。

· 提醒时间不对：绝对时刻（"23点"）由本地解析成"最近一次到来的该时刻"， 模型不负责算分钟差。日志里会打印解析结果与触发时刻，可直接核对。

· 补发问候没有发生：日志里搜索"问候补发"。 常见原因：程序启动时还没到问候时刻、处于静默时段、事件没有目标会话、 或等待 NapCat 连接超时（可调「补发等待 NapCat 的超时」）。每一种都会打印明确原因。

· 日志怎么看：默认是"精简模式"（只回尾部若干行）；勾选「显示完整日志」看自启动以来的全部输出。 排查时建议打开它，并按关键词搜索：回复审判、工具调用、 搜索预取、待办提取、问候补发、TTS。

· 日志文件：程序日志同时写入 app.log（程序目录；装到只读目录时在 %LOCALAPPDATA%\Lovomo）。文件超过「日志文件大小上限」（默认 5 MB）时， 会自动丢弃最早的记录。

六、几个容易被忽略的联动关系

· 回复概率门控只在「回复审判」开启时生效；只开心情值时不会影响回复。

· 主动消息/问候的历史承接依赖会话里已有记录，全新会话等于没有上下文。

· 「识图自动收藏表情」需要同时开启「表情包功能」，且模型没给出明确收藏判定时默认不收藏。

· 「分开发送」关闭时，下面的「语音分开发送」「文本分开发送」等选项会自动隐藏（它们只在那条路径上生效）。

· 待办提取的「触发关键词」是第一道门槛：消息不含其中任何一个词就不会被提取， 删掉「叫我」会导致"8点半叫我起床"这类消息被直接跳过（日志有提示）。

提示：若某项没显示，通常是因为它依赖的上级开关没打开。
