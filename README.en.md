# Lovomo

[简体中文](README.md) · **English**

Lovomo is an AI chat assistant with customizable characters. Chat in the app, or connect it to QQ or WeChat. Use local or cloud models, with voice as an option.

## Features

- **Chat and characters:** Set a persona, reply style and voice. Compare the saved persona with a draft using the same message, then apply the draft when you are happy with it.
- **Voice:** Use local GPT-SoVITS or cloud voice services. Choose a preview language and emotion voices, or design or clone a voice where the service supports it.
- **Memory:** Review chat history and see which conversation a memory came from. Edit, pin or forget memories for each character.
- **Diagnostics and settings:** Search settings by problem and review changes before saving. Use the message timeline and timing breakdown to see where a reply slowed down or failed.

### Extensions

- **Channels and profiles:** Connect QQ through NapCat or an official bot, or connect WeChat through ClawBot. Choose a character, model and profile for each channel.
- **Companion tools:** Add scheduled tasks, proactive messages, journals, a knowledge base or plugins as needed. Choose plugins you trust.

## Quick start

1. Download the Windows installer from the [releases page](https://github.com/slpk1ng/Lovomo/releases), install it and open Lovomo.
2. In Model Services, add a chat model with its service address, model name and any required key, then save.
3. Open Chat Console, select a character and send a greeting. You can preview the voice later in Diagnostics & Backup.
4. To chat from QQ or WeChat, link your account and select a character and model in Connections.

The tour appears on first launch. Resume or reopen it under Configuration → Restart Quick Start. Before moving to a new device, export a backup in Diagnostics & Backup and preview it before restoring.
