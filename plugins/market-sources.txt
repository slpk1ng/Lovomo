# 官方市场的第三方来源清单。
#
# 每行写一个「用户名/仓库名」（也接受直接粘 GitHub 地址），# 开头是注释。
# 清单里的仓库会按与官方市场相同的规则扫：名字以插件分支前缀
# （默认 lovomo_plugin）开头的分支即为一个插件，分支根目录放 plugin.yaml。
#
# 想让自己的插件进官方市场：
#   1. 把插件发布到自己仓库的 lovomo_plugin_<插件id> 分支（用程序里的「发布到分支」即可）；
#   2. 往本文件加一行自己的仓库地址，给本仓库提一个 Pull Request；
#   3. 合并后官方市场就会扫到它。
#
# 前提：官方市场仓库的「来源清单路径」要填成这个文件（配置文件 → 插件系统 → 来源清单路径）。
# 注意 GitHub 匿名读取有次数限制，清单别堆太多仓库。
#
# 示例（去掉行首的 # 即可生效）：
# your-name/your-lovomo-plugins
