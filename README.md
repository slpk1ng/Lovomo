# LTVM (Local TTS Voice Modulation)

基于本地大语言模型（LLM）与 GPT‑SoVITS 语音合成技术的 AI 角色聊天助手。支持接入 NapCat 连接 QQ，提供全功能的 WebUI 管理控制台。

## ✨ 功能特性

* **本地化运行**：数据不经过外部服务器，保障隐私安全。
* **AI 语音交互**：通过 GPT‑SoVITS 实现文本到语音的拟真合成。
* **情绪模拟**：支持多情绪切换、语气渐变、呼吸间隙与交叉淡化，让语音更自然。
* **角色定制**：可通过 WebUI 轻松设置角色人格、回复风格与提示词。
* **聊天管理**：支持多会话管理、历史记录查看与一键删除。
* **日志监控**：实时查看运行日志，方便排查问题。

### 🧩 扩展功能（全部可在 WebUI 中独立开关与配置）

* **定时任务与主动消息**：自定义间隔 / 每日 / 每周问候任务；长时间未互动时主动找话题；节日、纪念日与用户生日自动祝福；程序在问候时间之后才启动时自动补发当天漏掉的问候（可关）；静默时段与每日上限防打扰。
* **待办提醒**：聊天中说「提醒我…」自动创建（正则或 LLM 提取），到点自动发送提醒，WebUI 可视化管理。提醒话术可用 LLM 按角色人设现场生成（默认）或使用固定模板；LLM 失败/漏说事项时自动回退模板，不漏提醒。
* **实时流式回复**：边生成边逐句合成发送，大幅降低首句等待时间。
* **表情包**：按情绪目录分类的本地表情图，回复时按概率附带；识图时若 LLM 判定图片有趣/值得收藏可自动存入对应情绪分类，后续相同情绪回复按概率发出（收藏判定搭车在识图调用内完成，不额外增加模型请求）。
* **多角色对话**：每个角色拥有独立人设与语音；群聊中 @ 机器人后，按消息中出现的角色名路由回复，支持角色间互相接话（群聊默认需要 @ 才响应，可用 `group_need_at` 关闭；引用机器人消息视同 @）。
* **工具调用 (Function Calling)**：内置时间 / 计算 / 天气 / 网页读取，支持自定义 HTTP 与命令工具；每个工具可独立授权（用户白名单、调用上限）。
* **知识库 RAG**：上传文档自动分块向量化（本地向量库，无外部依赖），回答时自动检索注入。
* **用户画像**：按 QQ 记录昵称、生日、喜好，支持 LLM 自动提取与生日自动祝福。
* **动态上下文**：对话自动摘要 + 话题检测，长对话不降智。
* **统计面板**：消息量、情绪分布与趋势图表，LLM/TTS 耗时实时监控。
* **情绪音频管理**：WebUI 上传 / 试听各情绪参考音频与 asr.txt，一键新建或删除情绪。
* **数据导入导出**：配置、聊天记录（单个 / 全部打包）一键导出导入备份。
* **回复审判与心情**：LLM 先判断消息是否需要回复再开口；角色拥有随对话增减的持久化心情值，心情值低时回复概率按配置降低（WebUI 可开关与调参）。群聊中心情值按用户隔离：某位用户惹角色不开心只会降低对该用户的回复意愿，不影响其他成员。
* **工具误调防护**：消息不含任何工具触发词（时间/计算/天气/搜索/网址等）时不会进入工具调用流程，显著减少 LLM 乱调工具；触发词可在 WebUI 自行配置。
* **语音/文本分开发送分段**：分开发送时若 LLM 返回一整段未分句内容，会按 `。？！.!?` 自动切分后逐段合成语音与文字。
* **隐私保护**：可为 WebUI/聊天记录设置访问密码；删除会话时同步清理对应角色的心情记录。
* **防刷屏**：同一会话短时间消息过多时自动忽略多余消息，避免重复占用 LLM 拖慢正常回复。
* **托盘常驻**：关闭窗口默认最小化到系统托盘，任务栏托盘右键菜单提供「打开 LTVM / 重启 LTVM 控制台 / 退出 LTVM」。
* **检查更新**：定期从 GitHub 检查新版本，发现更新时在应用内弹窗提醒（纯浏览器访问同样提示）。

## 🖥️ WebUI 使用说明

程序启动后会自动打开控制台窗口（或通过浏览器访问 `http://127.0.0.1:11500`）。

* **配置文件**：设置 NapCat 地址、LLM 模型 API、TTS 服务地址、角色人格及情绪映射，以及各扩展功能的开关与参数；支持配置导入导出。
* **聊天记录**：查看与管理所有会话，支持批量删除与导入导出。
* **情绪音频**：可视化上传 / 试听各情绪的参考音频与 asr.txt。
* **定时任务**：定时问候、节日 / 生日事件与待办提醒管理。
* **统计面板**：对话统计图表与实时性能监控。
* **高级功能**：表情包、工具调用、知识库 RAG、用户画像。
* **日志输出**：实时查看系统运行状态。

## ⚙️ 配置说明

在 WebUI 中配置完成后点击「保存配置」，程序会生成 `config.json` 文件并持久化设置；定时任务、工具、事件等数据分别保存在 `data/` 目录下的 JSON 文件中。

### 核心配置项

|配置项|说明|
|-|-|
|napcat\_ws\_url|NapCat 的 WebSocket 地址|
|llm\_backend|LLM 后端类型：`ollama` 或 `openai`（LM Studio / llama.cpp 等 OpenAI 兼容服务）|
|llm\_base\_url|LLM 服务地址：Ollama 填 `http://127.0.0.1:11434`，LM Studio 填 `http://127.0.0.1:1234/v1`|
|llm\_model\_name|模型 ID，需与服务已下载 / 已加载的模型一致（WebUI 支持从文件夹或服务列表选择）|
|client\_base\_url|GPT‑SoVITS API 地址|
|ref\_audio\_root|参考音频根目录|
|model\_dir|TTS 模型文件夹|
|streaming\_enabled|实时流式回复开关|
|scheduler\_enabled|定时任务总开关|
|tools\_enabled|工具调用总开关|
|rag\_enabled|知识库 RAG 开关|
|profiles\_enabled|用户画像开关|

## ❓ 常见问题 (FAQ)

**Q：为什么窗口打不开？**
A：请确认已安装 Microsoft Edge WebView2 Runtime，或检查 `config.json` 中的 `webui\_port` 是否被占用。

**Q：为什么只有「保存配置」按钮，没有配置选项？**
A：通常是因为旧版 `config.json` 缺少字段。请删除程序目录下的 `config.json` 后重启。

**Q：为什么没有自动启动 TTS？**
A：请确认在 `config.json` 中 `auto\_start\_tts` 为 `true`，且 `tts\_start\_script` 路径正确。

**Q：主动消息 / 待办 / 工具调用等功能为什么不生效？**
A：请在「配置文件」页面开启对应的功能开关（如 `proactive\_enabled`、`todo\_enabled`、`tools\_enabled`），并按页面提示完成相关数据配置。

**Q：RAG 上传 PDF 失败？**
A：PDF 解析需要额外依赖：`pip install pypdf`；普通文本 / Markdown / 代码文件无需额外依赖。

## 📦 更新历史

### v1.2.0.0-beta

#### ✨ 新增

**模型与 LLM**

- WebUI 模型可视化选择：LLM / 识图模型可点「选文件夹」扫描本地模型，或点「服务列表」直接拉取服务端的模型 ID，不再需要手抄模型标识符；TTS 模型目录、参考音频、表情包目录等路径字段均支持「浏览」一键选择。
- 换模型后自动卸载旧模型（`llm_auto_unload_old`，默认开启）：新模型首次调用成功时自动卸载不再使用的旧模型，避免多个模型常驻挤爆显存、拖慢回复。
- 文本清洗屏蔽词（`text_clean_blocklist`）：LLM 回复中出现的指定字符 / 词在发送前剔除，语音与文字同时生效。
- 搜索关键词由 LLM 提取（`search_query_llm_extract`）：预取搜索前由模型从用户消息里提取关键词、剔除口语与无关字符，失败或超时自动回退规则提取。
- 情绪判定规则引导（`emotion_guide_enabled`，默认开启）：提示词写明各情绪的使用时机，亲密 / 被撩 / 欲拒还迎场景必须优先「害羞」，「平静」只作最后选择；可追加自定义规则（`emotion_guide_extra`）。

**消息与发送**

- NapCat 发送超时自动重试（`send_retry`）：QQ 偶发「NTEvent Timeout」导致整句丢失时自动重发一次。
- 语音 / 文本分开发送时按 `。？！.!?` 强制分段后逐句请求 TTS，文字与语音一一对应。
- 回复审判心情按「会话 + 用户 + 角色」隔离：群聊里某人惹角色不开心，只降低对其本人的回复意愿。
- 群聊 @ 对象上下文注入，减少 LLM 混淆被 @ 的是谁。
- 用户画像支持按对话替换 / 删除旧条目（likes_remove、clear_* 等），防止旧信息残留。
- 待办提醒话术可选 LLM 生成或预设模板（`todo_remind_mode`），模型失败自动回退模板，绝不漏提醒；提醒语音可单独指定情绪（`todo_voice_emotion`）。

**系统与 WebUI**

- API 密钥改为真加密存储：密钥绑定本机硬件信息派生加密密钥（HMAC-SHA256 流加密 + 完整性校验），config.json 拷到别的电脑无法解出密钥；WebUI 与导出文件中只显示密钥头尾各 4 位和实际长度（如 `sk-a****6789（18位）`）

- 托盘常驻：关闭窗口最小化到托盘，托盘右键「打开 LTVM / 重启控制台 / 退出」。
- 聊天记录访问密码保护（`webui_password`）。
- 防刷屏限流（`anti_spam_*`）：同一会话短时间消息过多时自动忽略，不占用 LLM。
- 定期从 GitHub 检查更新，发现新版本时应用内弹窗提醒（`update_check_*`）。
- TTS 排查日志（`tts_debug_log`）：打印台词、情绪、参考音频等合成细节；字符替换表可在 WebUI 自定义（`tts_char_map`）。

#### 🛠 修复

**回复与情绪**

- 害羞的对话却用平静音色：模型输出的情绪名带中文 / 英文 / 变体（如「害羞」「shy」「haixiu。」）时被严格匹配打回——现在自动解析别名，解析不出才回退默认音色。
- 主动消息把模型的思考内容念了出来——请求、解析、流式、发送四层剥离思考内容。
- LLM 把自身回复或说话人标签误当作消息内容、把用户发的表情包说成「自己的」——标签规整 + 图片身份规则（`image_identity_guard_enabled`）。

**工具与搜索**

- 发图片问「帅不帅」却被拿去网上搜索：主观评价类问题不再触发搜索（提示词明确禁止 + 模型发起的此类搜索直接拦截），工具判断为 LLM 模式时同样生效。
- 用户抱怨「为什么要去搜呢」本身又触发一次搜索（死循环）：搜索意图识别现在会忽略否定 / 质疑语境里的「搜」字。
- 不需要调用工具时 LLM 误调工具——消息不含触发词就不进工具流程，触发词可在 WebUI 配置。
- 调用搜索 / 网页工具报 `400 Bad Request`：发给服务的 tool_calls 消息形态不合规——发送前统一规整，报错附带服务端原始信息。
- 搜索关键词不准：整句口语直接当搜索词——剔除否定分句与请求语，只留搜索目标。
- 回复因相似度过高被打回重生成时，把同样的搜索再跑一遍（白等 30 秒以上）——预取搜索结果按关键词缓存，直接复用。

**TTS 与语音**

- 语音比文字「少一句 / 少一个词」：清洗白名单静默删符号、合成参数传反、中日句数对不齐时退化成整段合成——现在清洗只做等价替换并留日志、参数自愈纠正、句数不齐按字符权重并段，文字与语音逐段对应。
- 文字逐条发但语音粘成一整条（separate_send 下短句又被合并回去）。
- Windows 中文环境打印 ♪ 等符号抛 UnicodeEncodeError 打断合成。

**主动消息**

- 非静默时段也长期不发：计划时刻每次重算、闲置计时重启即丢、当日次数不落盘——现在计划只定一次、闲置计时按最后发言恢复、状态持久化到 `data/proactive_state.json`，并补齐诊断日志。

**表情包**

- 纯风景 / 无文字图片被误收藏、GIF 被压成 PNG、收藏后发不出来——收藏需明确判定与具体理由、GIF/WebP 原样保留字节、自动同步通用池（`sticker_capture_any_pool`）。

**其他**

- RAG 在非 Ollama 后端下误判「嵌入模型未配置」。

**稳定性与数据安全**

- 会话记忆 / config.json / 心情 / 画像 / 事件 / 定时任务等全部 JSON 文件改为原子写入，进程被强杀不再产生半截文件；损坏时自动备份为 `.corrupt` 而不是静默清零。
- 修复对话后摘要任务把旧会话快照写回、覆盖刚保存的聊天记录的并发竞态；判定不回复或生成失败时用户消息也会正常落盘。
- config.json 损坏时先备份（`.corrupt`）再重建，不再直接用默认配置覆盖。
- 表情包上传增加图片格式白名单与 10MB 大小限制，回包加 nosniff，会话 Cookie 加 httponly，堵住存储型 XSS。
- 导出的配置文件不再包含明文 API 密钥（掩码导出，重新导入自动还原）；保存角色等旁路写盘路径不再把密钥写成明文。
- 流式回复被截断时，抢救出的尾句现在会正常发送，而不是只写进历史。
- 识图请求中失效图片源不再导致后续图片 URL 与内容错位。
- 工具单回复调用配额改为按回复隔离，多群并发不再互相清零或互相占额；参数解析失败不再消耗次数。
- web_fetch 修复重定向校验失效（可被 302 跳转绕过内网防护）；DNS 校验移出事件循环不再卡顿全局；自定义命令工具输出按 UTF-8 容错解码；自定义 HTTP 工具遇到重定向返回明确错误而不是空结果。
- 待办提醒发送失败时保留待提醒状态，不再标记已完成；节日问候文案生成失败不再误标已发送。
- 定时任务增加重叠保护，回调慢于间隔时跳过本轮，不再堆积并发。
- 统计面板「今天」与逐日图表统一按本地零点分桶，不再把 0-8 点计入昨天。
- 修复合并语音时采样率/声道不一致导致的变速变调与合并失败、合成失败时临时文件泄漏、TTS 启动失败时并发消息各等 60 秒、路径配置为单个字符时启动崩溃。

#### ⚡ 优化

- 连接类故障（LLM / 嵌入服务不可达）报错附带目标地址与排查建议，启动时自动探测。
- WebUI「保存配置」与默认配置合并，界面未渲染的字段不再被丢掉。
- 表情包收藏判定搭车识图调用（零额外请求）；心情统计可展开多会话记录；工具测试支持自定义 JSON 参数；JSON 编辑区可拉伸。
- 删除会话时同步清理对应角色的心情记录。
