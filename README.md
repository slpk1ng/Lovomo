# Lovomo

**简体中文** · [English](README.en.md)

Lovomo 是一个可自定义角色的 AI 聊天助手。你可以先在界面里试聊，也可以接入 QQ 或微信。支持本地和云端模型，语音可按需启用。

## 功能

- **聊天与角色**：设置角色人设、回复风格和音色。用同一句消息比较已保存的人设与草稿，满意后再应用。
- **语音**：支持本地 GPT-SoVITS 和云端语音服务，可切换试听语言、使用情绪音色，也可按服务能力设计或复刻音色。
- **记忆**：查看聊天记录及角色回忆的会话来源，修改、置顶或忘掉回忆。不同角色分别管理。
- **诊断与设置**：按问题搜索设置，保存前核对改动。查看消息处理时间线、首句等待和分段耗时，定位模型、语音或投递问题。

### 扩展功能

- **多平台与预设**：QQ 可用 NapCat 或官方机器人，微信可用 ClawBot。各通道可选不同的角色、模型和配置文件。
- **陪伴与工具**：可按需使用定时任务、主动消息、日记和知识库，或通过插件扩展能力。请选用可信插件。

## 快速开始

1. 从项目的 [发布页](https://github.com/slpk1ng/Lovomo/releases) 下载 Windows 安装包，安装并打开 Lovomo。
2. 在「模型服务」添加聊天模型，填写服务地址、模型名和服务需要的密钥，然后保存。
3. 打开「聊天测试」，选择角色并发送一句问候。语音可以稍后在「运行诊断与备份」试听。
4. 想从 QQ 或微信聊天时，到「接入方式」绑定账号并选择角色和模型。

首次打开会看到操作引导。可从「配置文件 → 重新查看新手引导」继续或重看。迁移电脑前，可在「运行诊断与备份」先导出备份，再在新设备预览及恢复。
