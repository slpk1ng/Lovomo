# Lovomo

**简体中文** · [English](README.en.md)

> 仓库地址：<https://github.com/slpk1ng/Lovomo>

基于本地大语言模型（LLM）与 GPT‑SoVITS 语音合成技术的 AI 角色聊天助手。支持接入 NapCat 连接 QQ，提供全功能的 WebUI 管理控制台。

## ✨ 功能特性

* **本地化运行**：数据不经过外部服务器，保障隐私安全。
* **AI 语音交互**：通过 GPT‑SoVITS 实现文本到语音的拟真合成。
* **情绪模拟**：支持多情绪切换、语气渐变、呼吸间隙与交叉淡化，让语音更自然。
* **角色定制**：可通过 WebUI 轻松设置角色人格、回复风格与提示词。
* **聊天管理**：支持多会话管理、历史记录查看与一键删除。
* **日志监控**：实时查看运行日志，方便排查问题。

### 🧩 扩展功能（全部可在 WebUI 中独立开关与配置）

* **定时任务与主动消息**：自定义间隔 / 每日 / 每周问候任务；长时间未互动时主动找话题；节日、纪念日与用户生日自动祝福；程序在问候时间之后才启动时自动补发当天漏掉的问候（可关）；静默时段与每日上限防打扰。
* **待办提醒**：聊天中说「提醒我…」自动创建（正则或 LLM 提取），到点自动发送提醒，WebUI 可视化管理。提醒话术可用 LLM 按角色人设现场生成（默认）或使用固定模板；LLM 失败/漏说事项时自动回退模板，不漏提醒。
* **实时流式回复**：边生成边逐句合成发送，大幅降低首句等待时间。
* **表情包**：按情绪目录分类的本地表情图，回复时按概率附带；识图时若 LLM 判定图片有趣/值得收藏可自动存入对应情绪分类，后续相同情绪回复按概率发出（收藏判定搭车在识图调用内完成；分类与命名另走一次不带人设与心情的中立调用，避免被角色当时的情绪带偏）。
* **多角色对话**：每个角色拥有独立人设与语音（未填写提示词的角色不会套用默认角色的人设）；群聊中 @ 机器人后，按消息中出现的角色名路由回复，支持角色间互相接话（群聊默认需要 @ 才响应，可用 `group_need_at` 关闭；引用机器人消息视同 @）。
* **工具调用 (Function Calling)**：内置时间 / 计算 / 天气 / 网页读取，支持自定义 HTTP 与命令工具；每个工具可独立授权（用户白名单、调用上限）。
* **知识库 RAG**：上传文档自动分块向量化（本地向量库，无外部依赖），回答时自动检索注入。
* **用户画像**：按 QQ 记录昵称、生日、喜好，支持 LLM 自动提取与生日自动祝福。
* **动态上下文**：对话自动摘要 + 话题检测，长对话不降智。
* **统计面板**：消息量、情绪分布与趋势图表，LLM/TTS 耗时实时监控。
* **情绪音频管理**：WebUI 上传 / 试听各情绪的参考音频，逐段填写参考文字（可用一键语音识别自动生成），一键规整时长，一键新建或删除情绪。
* **数据导入导出**：配置、聊天记录（单个 / 全部打包）一键导出导入备份。
* **回复审判与心情**：LLM 先判断消息是否需要回复再开口；角色拥有随对话增减的持久化心情值，心情值低时回复概率按配置降低（WebUI 可开关与调参）。心情值还会直接影响说话风格：偏低转冷淡、低迷转烦躁并把回复压到 1~2 句（`mood_style_enabled`，默认开启）。群聊中心情值按用户隔离：某位用户惹角色不开心只会降低对该用户的回复意愿，不影响其他成员。
* **工具误调防护**：消息不含任何工具触发词（时间/计算/天气/搜索/网址等）时不会进入工具调用流程，显著减少 LLM 乱调工具；触发词可在 WebUI 自行配置。
* **语音/文本分开发送分段**：分开发送时若 LLM 返回一整段未分句内容，会按 `。？！.!?` 自动切分后逐段合成语音与文字。
* **隐私保护**：可为 WebUI/聊天记录设置访问密码，另可再设一个**二级密码**，读取聊天记录、保存、导入导出、安装插件、删除、发布与下架等敏感操作要再输一次才能执行；删除会话时同步清理对应角色的心情记录。
* **防刷屏**：同一会话短时间消息过多时自动忽略多余消息，避免重复占用 LLM 拖慢正常回复。
* **托盘常驻**：关闭窗口默认隐藏到系统托盘（窗口从屏幕和任务栏一并消失），托盘右键菜单提供「打开 Lovomo / 重启 Lovomo / 退出 Lovomo」；程序已在运行时再次双击 exe 只会把已有窗口唤到前台，不会起第二个进程。
* **检查更新**：定期从 GitHub 检查新版本，发现更新时在应用内弹窗提醒（纯浏览器访问同样提示）。
* **插件系统**：上传 `.zip` 或从在线市场一键安装插件，给程序加功能或换皮肤；插件可声明式生成设置界面，也可自带 HTML 功能页与独立的 `webui.html` 页面；安装前自动静态安全扫描，高危操作需显式确认；卸载时可选择保留插件配置与数据；作者还能把自己写的插件一键发布到 GitHub 市场仓库上架。

## 🚀 快速开始

### 直接安装

1. 下载最新的 `Lovomo_Setup.exe`。
2. 运行安装程序，选择安装路径并完成安装。
3. 双击桌面图标运行。

## 🖥️ WebUI 使用说明

程序启动后会自动打开控制台窗口（或通过浏览器访问 `http://127.0.0.1:11500`）。

* **配置文件**：设置 NapCat 地址、LLM 模型 API、TTS 服务地址、角色人格及情绪映射，以及各扩展功能的开关与参数；支持配置导入导出。
* **插件市场（测试版）**：上传 `.zip` 插件包、打开插件目录、刷新在线市场（官方 / 第三方），安装前自动做安全扫描。官方市场读哪个仓库由「配置文件 → 插件系统 → 官方市场仓库」决定，插件以目录形式提供 —— 市场仓库里一个插件一个 `plugins/<分类>/<插件id>/` 目录（分类取自插件清单的 `category`，缺省归入「其他」），条目记在 `plugins/index.json`（读的是仓库的默认分支）；工具栏可按分类筛选，每个分类后面跟着插件数量，与搜索、排序叠加。索引里没有条目时才回退去扫插件分支，分支列表按页拉全（超过 100 条也不会漏）。「来源清单路径」指向市场仓库里的一份清单（每行一个「用户名/仓库名」）时，官方市场还会把清单里这些仓库一起扫进来 —— 插件作者把清单加一行、提一个 Pull Request，合并后就上架了，不需要给仓库写权限。程序启动时在后台静默预取一次在线市场，进入该页即可直接看到列表，不占用启动时间、也不打断操作；点「刷新市场」才会强制重新拉取。
* **插件**：管理已安装插件（启用 / 停用 / 卸载，卸载时可选择保留配置与数据），卡片右上角可置顶，带功能页的插件点卡片即可进入设置，带 `webui.html` 的可以「打开webui」。**新装的插件一律是停用状态**，由你自己到这一页点「启用」才会加载（覆盖升级沿用原来的开关，不会把用户的选择改掉）。「发布到市场」也在这里 —— 一键发布把插件写进市场仓库的 `plugins/<分类>/<插件id>/` 目录（改过分类时旧目录一并删掉）、同步更新 `plugins/index.json`，并按白名单现场打成 zip 作为该版本 Release 的附件（下载量与收藏量就来自 Release），版本标签为 `<插件id>-v<版本>`；某个版本是否已上架按**当下的市场索引**（外加版本标签）判定，不读市场页那份 30 分钟缓存 —— 别人直接在 GitHub 上删掉插件，回到面板就会立刻看到它不再是已上架；本机发布 / 下架过的记录另存在 `publish_state.json`（重启仍生效、24 小时后作废），刚推上去或刚删掉的那几秒也算数。版本没往上走的插件不给发布按钮、改为提示「当前版本已发布过」（后端同样会拒掉不更高的版本，手工调接口也绕不过去）。已上架的插件那一行还有「下架」按钮：删掉市场里的分类目录、索引条目与该插件的全部版本标签和 Release。同一行只会给一个动作 —— 要么「发布」，要么「已发布过」+「下架」，不会两个按钮并排；发布 / 下架成功后面板立刻切到新状态（不等接口往返），推送期间「发布」按钮不可点，同一个版本不会被重复推。
* **聊天记录**：查看与管理所有会话，支持批量删除与导入导出；列表可切换排序 —— 按角色（同角色聚在一起、组内按最新对话）、按最新对话、按最旧对话，后两者全局按时间排，不再按角色分组。
* **情绪音频**：可视化上传 / 试听各情绪的参考音频，逐段填写参考文字，一键规整时长与语音识别。
* **定时任务**：定时问候、节日 / 生日事件与待办提醒管理。
* **统计面板**：对话统计图表与实时性能监控。
* **高级功能**：表情包、工具调用、知识库 RAG、用户画像。
* **日志输出**：整页铺满内容区，实时查看系统运行状态，日志区右上角可勾选「显示完整日志」；程序日志写入 `app.log`（程序目录，装到只读目录时为 `%LOCALAPPDATA%\Lovomo`），超过「日志文件大小上限」（默认 5 MB）时自动丢弃最早的记录。
* **使用教程**：内置图文教程，按「先配通、再调优、出问题怎么查」整理。
* **界面语言**：侧边栏左下角可切换「简体中文 / English」，界面文案与提示信息即时切换；选择会记住，刷新页面或重启程序后仍然生效。

## ⚙️ 配置说明

在 WebUI 中配置完成后点击「仅保存」（需要顺带重启 TTS 时用「保存并重启TTS」），程序会生成 `config.json` 文件并持久化设置；定时任务、工具、事件等数据分别保存在 `data/` 目录下的 JSON 文件中。**`config.json` 与 `data/` 固定存放在 `%LOCALAPPDATA%\Lovomo`**，不跟安装目录绑在一起 —— 换目录重装、覆盖升级都能接着用（老版本写在程序目录里的那份，首次启动会自动搬过去）；插件与发布记录同样在这个目录下。卸载时会逐项询问是否删除配置、聊天记录与插件，默认一律保留。

### 核心配置项

|配置项|说明|
|-|-|
|napcat\_ws\_url|NapCat 的 WebSocket 地址|
|llm\_backend|LLM 后端类型：`ollama` 或 `openai`（LM Studio / llama.cpp 等 OpenAI 兼容服务）|
|llm\_base\_url|LLM 服务地址：Ollama 填 `http://127.0.0.1:11434`，LM Studio 填 `http://127.0.0.1:1234/v1`|
|llm\_model\_name|模型 ID，需与服务已下载 / 已加载的模型一致（WebUI 支持从文件夹或服务列表选择）|
|client\_base\_url|GPT‑SoVITS API 地址|
|ref\_audio\_root|参考音频根目录|
|model\_dir|TTS 模型文件夹|
|streaming\_enabled|实时流式回复开关|
|scheduler\_enabled|定时任务总开关|
|tools\_enabled|工具调用总开关|
|rag\_enabled|知识库 RAG 开关|
|profiles\_enabled|用户画像开关|

## ❓ 常见问题 (FAQ)

**Q：为什么窗口打不开？**
A：请确认已安装 Microsoft Edge WebView2 Runtime，或检查 `config.json` 中的 `webui\_port` 是否被占用。

**Q：为什么配置页里有些选项看不到？**
A：多数字段是**按条件显示**的：TTS 推理细节要在「隐藏高级 GSV 参数」关闭时才出现，采样参数要先打开「启用 LLM 采样参数」，插件系统、软件更新等分组要先打开对应总开关。这是正常行为。

**Q：为什么没有自动启动 TTS？**
A：请确认在 `config.json` 中 `auto\_start\_tts` 为 `true`，且 `tts\_start\_script` 路径正确。

**Q：主动消息 / 待办 / 工具调用等功能为什么不生效？**
A：请在「配置文件」页面开启对应的功能开关（如 `proactive\_enabled`、`todo\_enabled`、`tools\_enabled`），并按页面提示完成相关数据配置。

**Q：RAG 上传 PDF 失败？**
A：PDF 解析需要额外依赖：`pip install pypdf`；普通文本 / Markdown / 代码文件无需额外依赖。
