# 喵喵皮肤・回复追加（meow-skin）

一个「皮肤 + 功能」二合一的示例插件，演示 Lovomo 插件系统能做的两件事：

1. **深度换肤** —— 不只是换颜色，同时重排布局、调整间距/字号/圆角与组件形态；
2. **回复追加** —— 一个开关，开启后每轮 LLM 回复发送完成会再单独发一条
   「喵～」文字和一条喵叫语音。

插件**不改动 main.py**，全部能力通过清单声明 + 约定钩子实现。安装方式：

> WebUI →「插件市场（测试版）」→「上传插件包 (.zip)」→ 选 `meow-skin.zip`

安装时会看到安全扫描结果（本插件只有一条 medium 级「写文件」，因为要把
用户设置存进自己的 data 目录）。装好后在左侧栏「**插件**」页点这张卡片
空白处，即可进入它的功能页。

---

## 1. 换肤

样式写在 `theme.css`，通过主程序注入的 CSS 变量读取你在插件功能页里的设置：

| 变量 | 来源 | 含义 |
| --- | --- | --- |
| `--skin-bg-image` | `skin.background` | 自定义背景图片 URL |
| `--skin-bg-repeat` / `--skin-bg-size` | `skin.background` | 铺满方式（cover / contain / repeat） |
| `--skin-bg-opacity` | `skin.background` | 背景不透明度 |
| `--skin-accent` | `skin.accent` | 主色取色器 |
| `--skin-block-opacity` | `skin.vars` | 区块图层的不透明度（卡片、输入框、按钮、日志区等） |
| `--skin-radius` | `skin.vars` | 圆角大小 |
| `--skin-line-color` | `skin.vars` | 分隔线 / 边框颜色 |
| `--skin-surface-color` | `skin.vars` | 区块底色（与透明度叠加） |

> 透明度会作用到**所有**带底色的面：区块、卡片、通用数据表（含表头与悬停行）、
> 输入框、下拉框、按钮、标签/徽章、聊天记录页的操作条与列表、聊天记录弹窗
> （标题条 / 工具条 / 气泡）、日志区，以及区块里嵌套的小块。嵌套层用更浅的
> 一档，避免叠在一起反而更白。
>
> 带色相的面（用户气泡的绿、「启用」徽章的绿、「删除」按钮的红…）不会被换成
> 中性白，只按同一个透明度降 alpha —— 颜色含义留着，同时跟着滑条走。
> 红/橙这种"白字压重色"的按钮额外留了一个透明度下限，免得调太透时看不清字。

调整的四类样式：

- **排版**：侧边栏宽度、内容区留白、卡片栅格间距；
- **间距**：菜单项、表单行、卡片内边距、区块外边距；
- **字号**：正文行高、标题层级、标签与辅助文字大小；
- **组件样式**：圆角、阴影、悬停位移、聚焦描边、滚动条。

> 加新面板时要往 `theme.css` 的"最外面那一层"清单里补类名 ——
> 漏掉的那些元素会保持纯白，看起来就是"透明度没生效"。

区块底色用 `color-mix()` 而不是 `rgba()` 计算：`rgba()` 只能调"整体不透明度"，
外壳元素一旦自带 `opacity`，里面的文字和子元素也会跟着变淡；`color-mix()`
只改这个颜色本身的 alpha，文字始终保持纯色。

背景层用固定定位的伪元素铺，不透明度可调，且不会挡住正文 ——
关键是把 `.main-content` 改为 `transparent`，否则它会盖住背景层。

底色的规则挂在 `html.skin-on` 下：只有你在功能页里打开「应用这套外观」，
页面才会加上 `skin-on` 类，插件一装上不会强行改掉原来的背景。

## 2. 回复追加开关

功能页里有两个控件：**喵喵追加**（开关）和 **追加次数**（1~5 的滑条）。
状态存在插件私有设置 `settings.json` 里，插件运行时读取。

> 设置改完不会立刻生效：功能页右下角的**「保存并重载」**才是应用入口。
> 这样一次调好几项不会中途反复生效，也避免拖动滑条时每一帧都重载插件。

也可以在群里发指令控制：

| 指令 | 作用 |
| --- | --- |
| `#喵开关` | 翻转开关 |
| `#喵开关 on` / `#喵开关 off` | 显式开启 / 关闭 |
| `#喵状态` | 查看当前状态 |

开启后，每轮 LLM 回复发送完成时：

1. 单独发一条文字 `喵～`（按「追加次数」重复）；
2. 再单独发一条喵叫语音（走主程序自己的 TTS 链路合成，失败自动降级为只发文字）。

同一会话上一轮追加还没结束时会跳过本轮，避免连发叠成一串。

---

## 3. 卸载即还原

- **皮肤**：`theme.css` 只在插件启用时才被主程序拼接进页面，禁用/卸载后
  自动消失，页面立刻回到默认外观；
- **追加**：`on_unload` 钩子会把开关置为关闭，即使插件之后又被重新启用，
  也不会「偷偷」继续追加。

这是插件系统的设计约定：**插件对主程序的改动必须是可撤销的**。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `plugin.yaml` | 清单：id / 名称 / 版本 / 归属 / `skin` 段 / `features` 段 / `panel` 段 |
| `theme.css` | 换肤样式 |
| `main.py` | Python 逻辑：注册指令、读取设置、回复完成追加 |
| `logo.png` | 列表与市场卡片上的图标（128×128） |
| `README.md` | 本文件，安装完成后自动弹窗展示 |
| `update.md` | 「查看历史更新」页里展示的版本日志 |

## 关于清单里的三个声明段

```yaml
skin:
  background: true          # 背景图选择器
  layout: true              # 布局标记
  accent: "#7c4dff"         # 主色取色器
  vars:                     # 任意 CSS 变量，主程序输出成 --skin-<name>
    - name: radius
      type: range
      min: 0
      max: 28
      default: 14
      unit: px
features:
  - key: meow_reply_enabled
    label: 喵喵追加
    type: bool
    default: false
panel:
  label: 喵喵皮肤
  title: 喵喵皮肤 · 外观与追加
```

- `skin` 段告诉主程序「这个皮肤支持哪些可调项」，前端据此渲染控件；
- `features` 段声明插件自己的可调项，前端自动渲染，**不用改前端代码**；
- `panel` 段声明「有功能页」——写了 `label`，卡片就能点进去，
  点进去的界面按 `skin` / `features` 自动生成；想完全自己画，再加一个
  `html: ui/panel.html` 即可。

想做一个自己的插件？照抄这个目录、改 id 和内容，然后重新打成 zip：

```bash
python .tmp_test/pack_plugin.py meow-skin
```
